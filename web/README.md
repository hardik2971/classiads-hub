# ClassiAds_Hub — Web Frontend (Next.js)

SEO-friendly public marketplace + user dashboard for ClassiAds_Hub. Consumes the
Laravel API (`/api/v1`). Built with **Next.js 16 (App Router) · React 19 ·
TypeScript · Tailwind CSS v4**.

## Run

```bash
# 1. Ensure the backend API is running (see ../backend/README.md) on :8000
# 2. Start the web app
cd F:\DI_PMS_Project\classify\web
npm run dev          # http://localhost:3000 (or next free port)
```

Config: `.env.local` → `NEXT_PUBLIC_API_BASE` (default `http://127.0.0.1:8000/api/v1`).
Backend CORS is enabled (`../backend/config/cors.php`).

## Architecture

- **API client** (`src/lib/api.ts`) — isomorphic, unwraps the `{success,data,message,meta,errors}`
  envelope, throws `ApiError`. `api.server.ts` (`serverApi`/`serverData`, reads the
  `ca_token` cookie) for Server Components; `api.client.ts` (`clientApi`) for Client Components.
- **Auth** — Sanctum bearer token in the `ca_token` cookie. `AuthProvider`
  (`src/context/auth-context.tsx`) exposes `user/login/register/logout`.
- **SSR/SEO** — public pages (home, search, category, ad, seller, blog, jobs,
  CMS) are Server Components with `generateMetadata` + JSON-LD structured data.
- **Dashboard** — client-rendered, auth-gated (`src/app/dashboard/layout.tsx`).
- **Design system** — Tailwind v4 tokens in `globals.css` (`brand`/`accent`),
  primitives in `src/components/ui`.

> Next.js 16 notes honored: `params`/`searchParams` are awaited Promises;
> `cookies()` is async; plain `<img>` for API media (no remotePatterns config).

## Pages (Master Plan §4.2)

```
/                         Home (SSR: sliders, categories, featured sections)
/search                   Search results + filter sidebar + sort + pagination
/category/[slug]          Category landing (SEO)
/ad/[slug]                Ad detail (SSR + JSON-LD Product) + chat/offer/favorite
/seller/[id]              Seller public profile + ads + reviews + follow
/login /register          Auth (+ /verify-otp, /forgot-password)
/post-ad                  Multi-step ad creation (category→details→fields→location→images)
/checkout                 Payment-method selection (subscription + featured-ad boost)
/checkout/result          Payment success / pending / failed
/blog /blog/[slug]        Blog (SEO)
/jobs /jobs/[slug]        Jobs vertical + apply (JSON-LD JobPosting)
/page/[key]               CMS pages (about/terms/privacy/contact/faq)
/dashboard                Overview
/dashboard/ads            My Ads (+ /ads/[id]/edit, ★ Boost → /checkout)
/dashboard/favorites | chat | notifications | subscriptions | transactions
/dashboard/reviews        Reviews (given/received tabs)
/dashboard/applications | verification | profile
not-found                 404
error / global-error      Route + root error boundaries
loading                   Route-transition loading UI
/sitemap.xml /robots.txt  Next.js metadata routes (frontend SEO)
```

SEO: `/sitemap.xml` and `/robots.txt` are generated by the Next.js app
(`src/app/sitemap.ts`, `src/app/robots.ts`) from live category/ad/blog/job data
(best-effort — falls back to static routes if the API is unreachable). The
Laravel backend also serves a crawler-facing sitemap; both can coexist.
